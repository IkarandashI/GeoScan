# GeoScan — Space Navigation Simulation

Упрощённая симуляционная среда в **Unreal Engine 5**: процедурно генерируемая планетная система, космический аппарат с ограниченным запасом топлива, гравитационные манёвры и планировщик маршрутов с многокритериальной оптимизацией (топливо / время / риск).

## Требования к запуску

- Windows 10/11 x64
- Unreal Engine **5.8**
- Visual Studio 2026 (рабочая нагрузка «Разработка игр на C++»)

## Инструкция по запуску

1. Клонировать репозиторий.
2. ПКМ по `GeoScan.uproject` → **Generate Visual Studio project files**.
3. Открыть `GeoScan.sln`, собрать таргет `GeoScanEditor` (Win64, Development Editor).
4. Открыть карту `Content/Level/StartupLevel` и нажать **Play**.

Миссия автономна от начала до конца: при старте система генерируется по seed из сценария, планировщик строит маршрут (по выбранному критерию), и автопилот выполняет его — аппарат уходит со стартовой орбиты, при выгодных возможностях использует гравитационные манёвры у планет и должен пересечь границу системы (по умолчанию 120 а.е.). Итог миссии и метрики — в HUD и в логе.

### Управление

| Клавиши | Действие |
|---|---|
| `0–8` | ускорение времени (0 — пауза; 1× … 10 лет/сек) |
| `C` / `F` / `R` | фокус на аппарате / следующий фокус (звезда → планеты → аппарат) / сброс камеры |
| `P` | replanning — пересчёт маршрута из текущего состояния |
| `V` | debug-визуализация: сферы влияния, маршрут плана, маркеры манёвров |
| ПКМ + мышь / колесо / `WASD`,`QE` | вращение / зум / панорама |

### Консольные команды

- `GeoScan.Benchmark Seeds=10 StartSeed=1` — бенчмарк «seed × режим» с полным прогоном каждой миссии; CSV-отчёт в `Saved/Benchmarks/`.
- `GeoScan.SaveScenario <имя>` / `GeoScan.LoadScenario <имя>` — сохранение/загрузка сценария (JSON, `Saved/Scenarios/`).
- `GeoScan.Replan`, `GeoScan.DebugViz [0|1]` — то же, что клавиши `P` / `V`.

### Сценарии и визуал

- **Сценарий** — DataAsset `UScenarioConfig` (`Content/Scenarios/`): seed и параметры генерации системы, режим границы (фиксированный или `K × орбита внешней планеты`), параметры аппарата (массы, тяга, Isp, стартовое тело и орбита, лимиты), режим оптимизации с весами критериев, параметры поиска и модели риска. Пресеты: `DA_Scenario_FuelEfficient` / `DA_Scenario_TimeEfficient` / `DA_Scenario_Balanced`. Новые: Content Browser → Miscellaneous → Data Asset → ScenarioConfig.
- **Визуал** — Blueprint-подклассы `BP_Star` / `BP_Planet` / `BP_Spacecraft` (меш + параметризованный материал `M_BodyColor` с `BodyColor`/`EmissiveStrength`; C++ подставляет каждому телу детерминированный цвет). Какие классы спавнить — поля Star/Planet/Spacecraft Class в сценарии; пусто = C++-актёры без мешей.

## Архитектура (кратко)

Единый модуль `Source/GeoScan`, слои по папкам (домен — обычный C++; UObject — только конфигурационная поверхность):

| Папка | Назначение |
|---|---|
| `Core/` | астродинамика: кеплеровы коники (universal variables; Ньютон + страховочная бисекция), Lambert-решатель, сферы влияния, Циолковский, детерминированный RNG (PCG32) |
| `Gen/` | процедурная генерация системы по seed: иерархия тел, эфемериды как аналитические функции времени |
| `Sim/` | состояние аппарата (снимок коники), patched-conics переключения сфер влияния, планы манёвров, жёсткие ограничения, сухой прогон миссии (`MissionRunner`) |
| `Planner/` | критерии стоимости (`URouteCriterion`, Blueprintable, реестр — новые критерии без правки планировщика), модель риска [0..1], beam search по последовательностям тел с Lambert-рёбрами и гравманёврами; план валидируется проигрыванием перед выдачей |
| `Config/` | `UScenarioConfig` (DataAsset) + JSON импорт/экспорт |
| `Actors/`, `Systems/`, `UI/` | UE-слой: актёры тел и аппарата (позиции из эфемерид), подсистема симуляции (часы, warp, автопилот, replan, debug-виз), бенчмарк, HUD |

Физическая модель — **patched conics**: аналитические орбиты, мгновенные импульсы ΔV, расход топлива по Циолковскому, гравитационные манёвры как поворот гиперболической избыточной скорости в сфере влияния планеты. Разделение C++/Blueprint: вся математика и логика — C++; визуальное представление (меши, материалы, классы тел) — ассеты.

## Тесты

Automation-тесты, 28 шт. (фильтр `GeoScan`): астродинамика (Kepler/Lambert/Циолковский, регрессия долгих гипербол), детерминизм генерации, валидация и JSON round-trip сценариев, SOI-переключения, исполнение планов, три режима планировщика с **проигрыванием каждой миссии до границы**, replanning, бенчмарк, резолв визуальных классов пресетов.
